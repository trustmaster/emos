# Writing samples

Excerpts of documents **Alex wrote personally**, kept as few-shot examples for
[`../alex.md`](../alex.md). These teach register more effectively than the written rules do,
which is why this folder exists.

Add one with `/voice <path-or-url>`, or drop a file in and add a row below by hand.

## Two rules

**Strip it to prose.** Drop template scaffolding, tables of contents, embedded images, API
and interface reference tables, and anything that is structure rather than sentences. A
sample teaches voice; it is not an archive of the original document.

**Never include machine-drafted text.** Not even text you reviewed and approved. It will
teach the agent to reproduce the register you're trying to get away from. If a document is
mixed, cut the drafted sections — or keep them clearly labelled as an anti-pattern, which
is more useful than deleting them.

## Anonymize people content

These are excerpts of real writing, so they may carry real names, unpublished numbers, and
internal system names. If you're excerpting a review, a promo case, or anything about a
named person, anonymize it. The real record already lives under `02-people/`; the sample
only needs to demonstrate sentence shape.

If your vault repo is shared with anyone, uncomment this line in `.gitignore`:

```
# .agents/voice/samples/
```
